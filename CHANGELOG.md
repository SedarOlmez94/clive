## [0.1.0] - 2026-08-01

### Added

- Initial release of Clive: a local-first coding-assistant CLI powered by
  Ollama.
- Streaming chat and interactive multi-turn sessions.
- Autonomous multi-file agent workflows.
- Ollama management commands (`serve`, `pull`, `remove`, `recommend`).
- File editing with preview/apply flow and unified diff patch generation.
- Optional git safety checks and auto-stage on write.
- Shell completions for bash, zsh, fish, powershell, and elvish.
- Persistent configuration for default model, Ollama URL, and system prompt.
